# Bisho IDE — Package 8: Preview Workbench

توسعة قسم معاينة مشاريع الويب مع الحفاظ على آلية نسخ ملفات المشروع محليًا وفتح صفحة HTML عبر WebView.

## التحسينات

- أوضاع عرض سريعة للمعاينة: هاتف متجاوب، هاتف عريض (844px)، جهاز لوحي (768px)، وسطح مكتب (1280px) عبر ضبط viewport داخل الصفحة المعروضة فقط.
- أزرار الرجوع والتقدم في سجل تنقل WebView، مع تحديث حالتها حسب إمكانية التنقل الفعلية.
- وحدة تحكم قابلة للطي والتوسيع لتوفير مساحة أكبر للمعاينة.
- تصفية رسائل وحدة التحكم إلى الكل أو الأخطاء أو التحذيرات.
- التقاط console.assert وconsole.count وconsole.timeEnd وconsole.table بالإضافة إلى المستويات المعتادة.
- تسجيل أخطاء تحميل الموارد الفرعية بشكل منفصل عن أخطاء JavaScript.
- إبقاء عدد السجلات محدودًا بـ500 سجل لمنع تضخم الذاكرة أثناء جلسات المعاينة الطويلة.

## الملفات

- `lib/html_preview_screen.dart`

## الحدود

- أوضاع viewport محاكاة لأبعاد CSS الشائعة وليست محاكاة كاملة لأجهزة حقيقية أو لأبعادها الفيزيائية.
- لا يوجد حتى الآن محرر مباشر داخل المعاينة أو Hot Reload تلقائي؛ إعادة التحميل تعيد تجهيز نسخة المشروع المؤقتة.
- لا يعني ظهور أخطاء الموارد الفرعية أن الصفحة الرئيسية فشلت؛ قد تكون بعض الموارد اختيارية.

## التحقق

تمت مراجعة التغييرات نصيًا وفحص سلامة أرشيف ZIP بعد إنشائه. لم تتوفر أدوات Flutter/Dart في بيئة العمل، لذلك لم يتم تشغيل `flutter test` أو `flutter analyze` أو بناء APK.
